# Diplomado Backend

## Pasos para iniciar el servidor local

1. Tener instalado Docker (Docker Desktop o OrbStack)

2. Abrir la terminal

3. clonar el proyecto con git clone https://github.com/CarlosBaez10/backend-node-express.git

4. Ejecutar el comando docker-compose up --build -d --remove-orphans

5. Abrir en navegador http://localhost:3007/



## Tecnologías Utilizadas
* Lista de lenguajes de programación "Node.js", "Express", "MongoDB", "Docker".
